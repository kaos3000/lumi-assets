# Lumi · fondos de nivel

Los paisajes pintados que usa el juego **Lumi** como fondo de cada nivel («versión de paisajes»).

## Etiqueta `v2` (Lumi 1.5.0+): 60 niveles
- `fondos/nivel01.webp` … `fondos/nivel60.webp`: vertical (móvil), WebP 1536×2048 (3:4). 1–30 son idénticos a `v1`.
- `fondos_tv/nivel01.webp` … `fondos_tv/nivel60.webp`: horizontal (TV / pantalla apaisada), WebP 2560×1440 (16:9).
  Del 31 al 60 están compuestos en 16:9. Del 1 al 30 son una adaptación: la pintura vertical entera, centrada sobre una versión desenfocada y oscurecida de sí misma.
- URL: `https://raw.githubusercontent.com/kaos3000/lumi-assets/v2/<carpeta>/nivelNN.webp` (espejo jsDelivr `@v2`).

## Etiqueta `v1` (Lumi 1.2–1.4.x): 30 niveles verticales en `fondos/`.

El juego descarga bajo demanda, comprueba tamaño y SHA-256 y guarda la copia en el teléfono.
Las imágenes de una etiqueta no se modifican nunca; el arte nuevo va en una etiqueta nueva.
Este repositorio solo contiene imágenes. No incluye código del juego.
