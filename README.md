# Lumi · fondos de nivel

Los 30 paisajes pintados que usa el juego **Lumi** como fondo de cada nivel («versión de paisajes»).

- `fondos/nivel01.webp` … `fondos/nivel30.webp`
- Formato: WebP, 1536×2048 (3:4 vertical), unos 0,4 MB cada uno.
- El juego los descarga bajo demanda desde la etiqueta fija `v1`, comprueba su integridad (tamaño y SHA-256) y los guarda en el teléfono:
  `https://raw.githubusercontent.com/kaos3000/lumi-assets/v1/fondos/nivelNN.webp`

Este repositorio solo contiene estas imágenes. No incluye código del juego.
Las imágenes de la etiqueta `v1` no se modifican nunca; una versión nueva del arte irá en otra etiqueta (`v2`, …).
